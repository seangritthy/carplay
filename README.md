# Android CarPlay Radio & Digital Phone Key App

A native Android CarPlay micro application featuring full web app integration, live radio tuner, Google Maps split-screen driving navigation, Digital Phone Key NFC auto-unlock, and automated in-app updates.

## Features
- 🚗 **Android CarPlay & Automotive Support**: High-contrast driving interface with big touch controls.
- 🔑 **Digital Phone Key / NFC Auto-Unlock**: Automatically unlocks car and starts radio playback when NFC phone key is tapped.
- 📻 **Live Radio Receiver**: Pre-tuned active Cambodian radio streams (RNK 96 FM, VAYO 105.5, FM 103, etc.).
- 🗺️ **Built-in Google Maps Dual Screen**: Live Google Maps iframe navigation alongside radio tuning.
- 🔄 **In-App Auto Updater**: Automatically checks for and installs new updates from GitHub releases (`seangritthy/vdomov-apks`).

## Build Instructions

```bash
./build_apk.sh
```
